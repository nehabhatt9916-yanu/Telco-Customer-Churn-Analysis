

# 📊 Telco Customer Churn Analysis Dashboard
To better understand customer behavior and identify churn patterns, I worked on an end-to-end Data Analytics project focused on Telco Customer Churn Analysis using Power BI, Python, and Machine Learning.
This project helped me combine business intelligence, data storytelling, predictive analytics, and dashboard development into a single real-world analytics solution.
## 📌 Project Overview
This project focuses on analyzing customer churn behavior in the telecom industry using Power BI, Python, and Machine Learning techniques. The objective is to identify key churn drivers, understand customer risk segments, and provide actionable business recommendations to improve customer retention.

The project combines:
- Interactive Power BI dashboard
- Exploratory Data Analysis (EDA)
- Customer segmentation
- Machine Learning prediction model
- Business intelligence reporting

---

# 🎯 Business Problem
Customer churn is one of the biggest challenges in the telecom industry. Losing customers directly impacts revenue and business growth.

This project analyzes customer behavior patterns to:
- Detect churn trends
- Identify high-risk customers
- Understand factors affecting customer retention
- Build a predictive model for churn forecasting

---

# 📂 Dataset Information
The project uses the IBM Telco Customer Churn Dataset containing:
- 7,043 customer records
- 21 features
- Demographics
- Account information
- Service subscriptions
- Billing details
- Churn status

---

# 📈 Key Insights
- Overall churn rate: **26.54%**
- Month-to-Month contract customers show highest churn risk
- Fiber Optic users churn more compared to DSL users
- Customers with tenure below 12 months are most likely to churn
- Electronic check users show elevated churn behavior
- High monthly charges correlate with increased churn probability
